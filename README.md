# Teardown Archipelago:



[APWorld Files For Visibility (Not download)](https://github.com/Evereliquest/Archipelago/tree/Master/worlds/teardown)

[Steam Workshop Link](https://steamcommunity.com/sharedfiles/filedetails/?id=3708322400) 

## Setup Instructions:

1. Install the apworld and data.zip folder from the most recent release, then the and steam workshop mod from the link above.

2. Right Click Teardown on Steam and under manage click browse local files.

3. Extract the folder from the zip (data.zip), then paste the entire data folder over the `Teardown/data` folder, overwriting the current files with the new ones.

4. Launch the game and open the mod through the mod manager at least once, then you can open freely from the campaign button or the mod manager, and are setup to connect with the client


## Client Instructions

1. Do NOT have the game open, open the client through the archipelago launcher, and provide the Teardown.exe and savegame.xml (press the Windows button and R, then paste this in and click ok `%localappdata%\Teardown`)

2. Connect to server, the game will auto open

3. When wanting to apply received items or cash, disconnect the client, close the game, then reconnect the client, in that order.

*There is an option to turn off the mod, and launch the vanilla campaign, within the options tab of the main menu
